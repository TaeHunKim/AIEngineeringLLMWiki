# Agent Infrastructure

## Overview

**Agent Infrastructure** covers the foundation for building agents, deploying them to production, and observing and evaluating them: frameworks, deployment runtime, AgentOps, and Eval-Driven Development. Where [[en/AI/Engineering/Agent_Engineering/Agent_Techniques/Agent_Techniques|Agent Techniques]] covers what to design inside an agent, this category covers how to run and verify that agent.
