# Agent Techniques

## Overview

**Agent Techniques** collects the design building blocks and patterns reusable across any agent: workflow patterns, planning and reflection, memory, multi-agent coordination, and skills and protocols. They are not tied to a domain, so every case in [[en/AI/Engineering/Agent_Engineering/Agent_Applications/Agent_Applications|Agent Applications]] is built by combining them.
