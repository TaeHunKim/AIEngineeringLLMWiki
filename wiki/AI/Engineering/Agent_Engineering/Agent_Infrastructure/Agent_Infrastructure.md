# Agent Infrastructure (에이전트 인프라·운영)

## 개요

**Agent Infrastructure**는 에이전트를 만들고, 프로덕션에 배포하고, 관측·평가하는 기반을 다룬다. 프레임워크, 배포 런타임, AgentOps, Eval-Driven Development가 여기에 속한다. [[AI/Engineering/Agent_Engineering/Agent_Techniques/Agent_Techniques|Agent Techniques]]가 에이전트 안에서 무엇을 설계할지를 다룬다면, 이 카테고리는 그 에이전트를 어떻게 돌리고 검증할지를 다룬다.
