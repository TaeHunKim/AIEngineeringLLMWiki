# Agent Applications (에이전트 적용 사례)

## 개요

**Agent Applications**는 [[AI/Engineering/Agent_Engineering/Agent_Techniques/Agent_Techniques|Agent Techniques]]와 [[AI/Engineering/Agent_Engineering/Agent_Infrastructure/Agent_Infrastructure|Agent Infrastructure]]가 특정 도메인에서 조합된 에이전트 유형을 다룬다. 코딩, 심층 리서치, 컴퓨터 사용·음성, 장기 실행 자율 시스템이 여기에 속한다. 각 문서는 해당 도메인에 고유한 제약(권한 모델, 인용 검증, 지연시간 등)과 그에 맞춘 기법 조합에 초점을 둔다.
