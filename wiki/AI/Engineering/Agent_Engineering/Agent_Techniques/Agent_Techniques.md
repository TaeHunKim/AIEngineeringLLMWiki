# Agent Techniques (에이전트 기법)

## 개요

**Agent Techniques**는 어떤 에이전트에든 재사용할 수 있는 설계 구성 요소와 패턴을 모은다. 워크플로 패턴, 계획·반성, 메모리, 다중 에이전트 조정, 스킬과 프로토콜이 여기에 속한다. 개별 도메인에 묶이지 않으므로 [[AI/Engineering/Agent_Engineering/Agent_Applications/Agent_Applications|Agent Applications]]의 모든 사례가 이 기법들을 조합해 만들어진다.
